# Security

This development preview is moving to automatic access to ordinary open HTTP(S) Safari tabs through the user's Safari website permissions. Eligible tabs may contain signed-in content. Private windows, unsupported URLs, denied hosts and documents the extension cannot identify stay unavailable. Signed native storage publish/read-match/remove and the 0.2.1 installation passed; Safari tab operations and closed-popup recovery still require live acceptance.

Use GitHub Security → Report a vulnerability for private reports. Include version, trust boundary and impact, using fictional reproductions and status metadata. Exclude connection descriptors/credentials, cookies, account details, real tab lists, page captures and private logs. Page instructions are untrusted input. Never demonstrate a report using another person's account or data.

**Stop all agent access** in the popup persists until **Resume**, including after background restart. Disable the extension in Safari to stop it entirely. Ending one MCP client releases its lease; other clients may still use the shared local daemon, which exits after its unused idle interval. Stop prevents further dispatch, but an action already sent may complete and cannot be undone. Navigation invalidates old document handles; eligible new documents are discovered automatically.

Connection credentials are obtained through Safari's native extension channel using a private descriptor in a Team-prefixed macOS App Group. Node invokes the signed embedded helper using bounded stdin/stdout for descriptor operations; it must not access group/container storage directly. Native bundle metadata and signing establish membership. The earlier direct-container Node route failed with macOS EPERM and is not a fallback. They are held in background memory, never copied through a popup, placed in page content or written to extension storage. The bridge stays loopback-only and authenticates local requests; ordinary website origins are rejected. The native handler accepts no caller-supplied descriptor path or host.

This local boundary trusts the current user and their installed clients. It does not defend against a compromised local account or a malicious authorized agent. Automatic technical access does not authorize a purchase, message or account change beyond the user's request. Do not assume independent agents have exclusive control of a tab: mutable-tab arbitration is not implemented. A timed-out action may already have occurred; inspect before retrying.

The current extension considers at most the first 500 browser-query results before eligibility filtering. A discovery snapshot is cached up to five seconds and immediately invalidated by relevant browser events. The cap remains a discovery limit. Safari may suspend its Manifest V3 background execution; automatic event/alarms/wakeup recovery must be tested rather than inferred from timers.

The ordinary daemon log directory is `~/.local/state/safari-agent` with private ownership/modes. Direct filesystem descriptor storage is an explicit isolated-test override only. Never print helper read responses: their stdout is private IPC containing session credentials.
