Safari Agent

Checking access…

Open web tabs are available automatically within Safari's website permissions. Agents can use signed-in content and submit forms. Their actions still require your task authorization.

Connection is automatic through the local Safari Agent helper. There is no token to paste or per-tab Allow button. Navigation refreshes document access; old commands are rejected. Stop prevents further dispatch but cannot undo an action already sent.

Safari may suspend extension execution. Reopening Safari or this popup can reconnect; polling does not guarantee continuous background operation.
